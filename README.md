\# Spring Boot Todo API



A simple REST API built with Java and Spring Boot.



\## Features



\- Get all todos

\- Add a new todo

\- Mark a todo as done

\- Delete a todo



\## Endpoints



GET /todos



POST /todos



PUT /todos/{id}/done



DELETE /todos/{id}

\## Tech Stack



\- Java

\- Spring Boot

\- Maven



\## Project Status



Basic in-memory CRUD API. Data is not saved permanently yet.

Database support will be added later.
